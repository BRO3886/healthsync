{{/* Agent feature */}}
01

Built for AI agents

Agent Skills

Run healthsync skills install to give Claude Code (and compatible agents) the schema, CLI reference, and SQL examples they need to query your health data in conversation.

  • "What was my average resting heart rate last month?"
  • "How many hours did I sleep on average this week?"
  • "Show me my VO2 Max trend over the past year."
  • "Which workout type burns the most calories for me?"

The skill installs to ~/.claude/skills/healthsync/ and is automatically picked up by Claude Code on next session start.

{{/* Feature grid */}}
02

What it does

Parser

Streaming XML

Constant ~10MB memory footprint for 950MB+ exports. DTD-stripped via io.Pipe. 500k records in ~30 seconds.

Storage

Pure Go SQLite

WAL mode for concurrent reads. Batch inserts at 1,000 rows per transaction. INSERT OR IGNORE for automatic deduplication.

Server

Async HTTP API

POST /api/upload returns 202 Accepted immediately and parses in the background. Poll /api/upload/status for progress.

CLI

6 queryable metrics

  • Heart rate, steps, sleep
  • Blood oxygen (SpO2), VO2 Max
  • Workouts with duration & calories
  • Table, JSON, or CSV output
{{/* Install */}}
03

Install

macOS / Linux — one-liner
curl -fsSL https://healthsync.sidv.dev/install | bash
Go toolchain
go install github.com/BRO3886/healthsync@latest
Manual — download binary
tar -xzf healthsync-darwin-arm64.tar.gz
sudo mv healthsync /usr/local/bin/

Windows: download healthsync-windows-amd64.zip or healthsync-windows-arm64.zip from GitHub Releases and add the binary to your PATH.

{{/* Quick start */}}
04

Quick start

  1. Step 01 Export from iPhone

    Health app → Profile → Export All Health Data → save the .zip

  2. Step 02 Parse 
    healthsync parse export.zip -v
  3. Step 03 Query 
    healthsync query heart-rate --limit 10
healthsync query steps --from 2024-01-01 --format json
  4. Step 04 Install agent skill 
    healthsync skills install

    Your AI agent can now query your health data directly in conversation.

{{/* How it works */}}
05

How it works
ParserStreaming XML with DTD stripping via io.Pipe. Handles 500k+ records in ~30s.
StoragePure Go SQLite (modernc.org/sqlite). WAL mode, batch inserts (1000/tx), UNIQUE constraints for dedup.
ServerChi router. POST /api/upload returns 202, parses async, poll GET /api/upload/status.
CLICobra. parse, query, server, skills subcommands. --db, --format, --from/--to flags.
Skillsgo:embed. healthsync skills install writes schema + query docs to ~/.claude/skills/ for agent pickup.
