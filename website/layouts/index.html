Built for AI agents

The primary motivation for healthsync is to make Apple Health data accessible to AI coding agents. Run healthsync skills install to give your agent the schema, CLI reference, and SQL examples it needs to answer questions like:

  • "What was my average resting heart rate last month?"
  • "How many hours did I sleep on average this week?"
  • "Show me my VO2 Max trend over the past year."
  • "Which workout type burns the most calories for me?"

The skill installs to ~/.claude/skills/healthsync/ and is automatically picked up by Claude Code and compatible agents on next session start.

What it does

  • Parses .zip or .xml Apple Health exports via streaming XML (constant ~10MB memory for 950MB+ files)
  • Stores records in ~/.healthsync/healthsync.db (SQLite, WAL mode, deduplication via INSERT OR IGNORE)
  • Queries 6 metrics: heart rate, steps, SpO2, VO2 Max, sleep, workouts
  • Output as table, JSON, or CSV with date range filters
  • HTTP server with async upload (202 Accepted + progress polling) for Tailscale workflows
  • Agent skills for Claude Code and Codex CLI via healthsync skills install
  • Single binary, zero CGO dependencies (modernc.org/sqlite)

Install

macOS / Linux — one-liner installer:

curl -fsSL https://healthsync.sidv.dev/install | bash

Go — install from source via the Go toolchain:

go install github.com/BRO3886/healthsync@latest

Manual — download a pre-built binary from GitHub Releases (macOS and Linux, arm64 and amd64):

tar -xzf healthsync-darwin-arm64.tar.gz
sudo mv healthsync /usr/local/bin/

Windows users: download healthsync-windows-amd64.zip or healthsync-windows-arm64.zip from GitHub Releases and add the binary to your PATH.

Quick start

  1. Export from iPhone

    Health app → Profile → Export All Health Data → save the .zip

  2. Parse 
    healthsync parse export.zip -v
  3. Query 
    healthsync query heart-rate --limit 10
healthsync query steps --from 2024-01-01 --format json
  4. Install agent skill (optional) 
    healthsync skills install

    Your AI agent can now query your health data directly in conversation.

How it works
ParserStreaming XML with DTD stripping via io.Pipe. Handles 500k+ records in ~30s.
StoragePure Go SQLite. WAL mode, batch inserts (1000/tx), UNIQUE constraints for dedup.
ServerChi router. POST /api/upload returns 202, parses async, poll GET /api/upload/status.
CLICobra. parse, query, server, skills subcommands. --db, --format, --from/--to flags.
Skillsgo:embed. healthsync skills install writes schema + query docs to ~/.claude/skills/ for agent pickup.
